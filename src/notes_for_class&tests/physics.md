## 2.1 流体的运动

### 2.1.1 理想流体

理想特性
>绝对不可压缩——即密度不变——实际液体和流动中的气体（各处密度在流动中趋向均匀），均可看作不可压缩
>
>完全没有粘性——无相对运动的内摩擦力——不考虑粘滞系数

### 2.1.2 流场，流线与流管

>流速
>流场
>流线：流线密度——速度大小
>流管：在运动流体中取一横截面，周边流线围成的管状体S，V，P

### 2.2.1 稳定流动的连续性方程

稳定流动：流线上每一点的速度大小和方向不随**时间**变化，流线形状也不随时间变化。

对理想流体（不可压缩）
由质量流量守恒可得体积流量Q

```bash
Sv = 常量 = Q 
```

又称体积流量守恒定律
