2.使用R包

2.1几种常用包

1.dplyr(筛选，新增列，分组统计)

dplyr 是 tidyverse 核心包，专门做数据框(data.frame/tibble)清洗、筛选、变换，管道符 %>% 是标志性写法。

函数	作用	
select()	选择列（挑选变量）	
filter()	筛选行（按条件筛选样本）	
mutate()	新增/修改列	
group_by() + summarise()	分组统计汇总	
arrange()	排序

2.tidyr(表格长宽重塑，缺失值处理，拆并列)

也属于tidyverse，专门做数据规整（长宽表转换、缺失值处理）。

tidy data（整洁数据）规则：
1.每一列 = 1个变量
2.每一行 = 1条观测
3.每个单元格 = 单个值

函数	功能说明	最简示例	
pivot_longer()	宽表 → 长表，把多列收拢为「变量‑数值」两列	df %>% pivot_longer(cols=c(t0,t1,t2), names_to="time", values_to="val")	
pivot_wider()	长表 → 宽表，把分类变量展开为多列	df %>% pivot_wider(names_from=time, values_from=val)	
drop_na()	删除包含NA的行	df %>% drop_na()
df %>% drop_na(val)	
replace_na()	替换NA为指定值	df %>% replace_na(list(val = 0))	
separate()	一列按分隔符拆分为多列	df %>% separate(col, into=c("a","b"), sep="_")	
unite()	多列合并为一列	df %>% unite(newcol, c(a,b), sep="_")	
fill()	向上/向下填充缺失值（时序补数据）	df %>% fill(val, .direction = "down")	
complete()	补全缺失组合，生成显式NA	df %>% complete(id, time)	
nest()	把多行数据嵌套进list列（分组嵌套数据框）	df %>% nest(data = -group)	
unnest()	把嵌套list列展开还原普通行	df %>% unnest(data)

3.stringr(文本字符串处理)

tidyverse 字符串处理包，library(tidyverse) 加载；函数全部以 str_ 开头，输入优先接收向量，非常适合配合 dplyr 处理表格文本。

函数	功能说明	最简示例	
str_detect()	检测是否匹配模式，返回 TRUE/FALSE（用于filter筛选）	str_detect(x, "abc")	
str_subset()	直接返回匹配成功的文本	str_subset(x, "abc")	
str_extract()	提取第一个匹配到的内容	str_extract(x, "\\d+")	
str_extract_all()	提取全部匹配，返回列表	str_extract_all(x, "\\d+", simplify = TRUE)	
str_replace()	替换第一个匹配内容	str_replace(x, "a", "A")	
str_replace_all()	全部替换	str_replace_all(x, "a", "A")	
str_remove()	删除第一个匹配，等价替换成空	str_remove(x, "\\s")	
str_remove_all()	全部删除匹配字符	str_remove_all(x, "\\s")	
str_split()	按分隔符拆分字符串，输出list	str_split(x, "_")	
str_split_fixed()	拆分，输出固定列数矩阵	str_split_fixed(x, "_", n=2)	
str_c()	字符串拼接（替代 paste）	str_c(a,"_",b)	
str_glue()	格式化拼接字符串，支持大括号插值	str_glue("ID:{id}")	
str_length()	获取字符数量	str_length(x)	
str_trunc()	字符串截断	str_trunc(x, width=10)	
str_trim()	去除首尾空白空格换行	str_trim(x)	
str_squish()	去除首尾+中间多余空格，压缩空白	str_squish(x)	
str_to_lower()	全部转小写	str_to_lower(x)	
str_to_upper()	全部转大写	str_to_upper(x)	
str_to_title()	每个单词首字母大写	str_to_title(x)

4.lubridate(解析日期)

tidyverse时间日期包，专门处理日期‑时间，解决R原生日期繁琐解析；library(tidyverse)可加载，也可单独library(lubridate) 核心：快速解析各式各样文本日期、提取年月日时分秒、时间运算、处理时区。

函数	功能说明	最简示例	
解析日期（字符→日期）			
ymd()	年‑月‑日，自动识别分隔符 - / .	ymd("2026‑08‑05")	
myd()	月‑日‑年	myd("08‑05‑2026")	
dmy()	日‑月‑年（欧洲格式）	dmy("05‑08‑2026")	
ymd_hms()	解析 年‑月‑日 时:分:秒 完整时间	ymd_hms("2026‑08‑05 14:30:20")	
提取时间组件			
year()	提取年份	year(dt)	
month()	提取月份数字；month(dt,label=TRUE)返回月份名称	month(dt)	
day()	提取当月几号	day(dt)	
wday()	星期几，1=周日；label=TRUE输出星期名称	wday(dt,label=TRUE)	
hour()	小时	hour(dt)	
minute()	分钟	minute(dt)	
second()	秒数	second(dt)	
时间运算			
days(x)	天时间增量	dt + days(7)	
months(x)	月份增量	dt + months(1)	
years(x)	年份增量	dt - years(2)	
weeks(x)	周	dt + weeks(2)	
interval(start,end)	生成时间区间	interval(d1,d2)	
%within%	判断时间是否落在区间内	dt %within% interval(d1,d2)	
舍入对齐			
floor_date()	向下取整（按月/按周对齐）	floor_date(dt, unit = "month")	
ceiling_date()	向上取整	ceiling_date(dt, unit = "day")	
round_date()	就近舍入	round_date(dt, unit="week")	
时区			
with_tz()	转换显示时区，时刻不变	with_tz(dt,tz="Asia/Shanghai")	
force_tz()	强制修改时区，改变实际时刻	force_tz(dt,tz="Asia/Shanghai")

5.httr（爬取网页、调用API、接口传参）

用于R发送HTTP请求,常搭配jsonlite解析返回JSON，也是科研抓取公开数据、调取接口的标配工具。

函数	功能说明	最简示例	
GET()	发送GET请求（查询数据、读取网页，最常用）	GET(url = "https://xxx.com/api")	
POST()	发送POST请求（提交表单、上传数据、接口写入）	POST(url, body = list(name="test"))	
PUT()	更新资源接口专用	PUT(url, body = list(data=123))	
DELETE()	删除接口资源	DELETE(url)	
add_headers()	自定义请求头（UA、Token、授权、Cookie）	add_headers(Authorization = "Bearer 你的令牌")	
set_cookies()	携带Cookie发送请求	set_cookies(session="abc123")	
content()	解析接口返回结果（文本/JSON/网页源码）	content(res, type = "text")	
fromJSON()	将JSON文本转为R数据框（配合content使用）	fromJSON(content(res, "text"))	
status_code()	查看HTTP状态码（200成功/404找不到/401权限不足）	status_code(res)	
url_modify()	快速拼接GET请求参数	url_modify(base_url, query = list(page=1, size=10))

7.ggplot2(tidyverse核心绘图包)

图层式绘图语法（Grammar of Graphics 图形语法）。逻辑：数据 + 映射(aes) + 几何图层 + 坐标轴/主题/标注。加载：library(ggplot2) 或者 library(tidyverse)

#模版
ggplot(数据框, aes(x = x列名, y = y列名, color = 分组变量, fill = 填充分组)) +
  geom_xxx() +       # 几何图层（画什么图形）
  labs() +           # 标题坐标轴名字
  scale_xxx() +      # 坐标轴、颜色刻度
  theme_xxx()        # 主题样式

  函数	功能说明	最简示例

几何图层 geom_

geom_line()	折线图（时间序列）	geom_line(linewidth=1)	
geom_bar()	柱状图/条形图	geom_bar(stat="identity")

geom_boxplot()	箱线图，组间分布	geom_boxplot()	
geom_violin()	小提琴图	geom_violin()	
geom_density()	密度曲线	geom_density()	
geom_smooth()	拟合曲线、回归拟合	geom_smooth(method="lm")	
geom_text()	图上加文字标签	geom_text(aes(label=Species))	
geom_hline() / geom_vline()	水平/垂直参考线	geom_hline(yintercept=5,lty=2)	
标签与坐标轴 labs			
labs()	标题、x轴、y轴、图例名	labs(title="图标题",x="X轴",y="Y轴",color="物种")	
xlim() ylim()	设置坐标轴范围	xlim(4,8)

8.Shiny(R语言交互式网页应用框架)

不需要懂HTML/CSS/JS，只用R代码就做网页APP；可本地运行、部署服务器/shinyapps.io。 结构固定分为两大块：UI界面(前端) + Server逻辑(后端)

函数	功能说明	最简示例	
UI布局与容器			
fluidPage()	流体页面，基础页面容器	fluidPage(...)	
titlePanel()	网页大标题	titlePanel("演示APP")	
sidebarLayout()	侧边栏布局（最经典）	侧边栏+主面板	
sidebarPanel()	侧边栏，放控件	sidebarPanel(...)	
mainPanel()	主面板，放图、表格结果	mainPanel(...)	
输入控件 input（用户交互）			
sliderInput()	数值滑块	sliderInput("num","数字",min=1,max=100,value=50)	
selectInput()	下拉选择框	selectInput("sp","物种",choices=unique(iris$Species))	
radioButtons()	单选按钮	radioButtons("opt","选择",c("A","B"))	
checkboxInput()	单个复选框	checkboxInput("show","显示线条")	
textInput()	文本输入框	textInput("txt","输入文字")	
actionButton()	执行按钮，点击触发计算	actionButton("go","运行")	
输出 output（展示结果）			
plotOutput("p1")	绘图输出位置	UI里放置绘图区域	
tableOutput("tbl")	表格输出位置	展示数据框表格	
textOutput("txtout")	文本输出位置	输出文字	
Server渲染函数			
renderPlot({})	渲染ggplot/base图	output$p1 <- renderPlot({ ggplot(...) })	
renderTable({})	渲染表格	output$tbl <- renderTable({ df })	
renderText({})	渲染文本	output$txtout <- renderText({...})	
reactive({})	响应式变量，封装计算，多次复用	data_react <- reactive({ input$num })	
isolate()	屏蔽响应，不随输入自动更新	isolate({ ... })	
observeEvent()	监听按钮点击事件	observeEvent(input$go,{ ... })	
运行&部署			
shinyApp(ui, server)	组装app，返回应用对象	app <- shinyApp(ui,server)	
runApp(app)	本地启动运行	runApp(app)

9.Rio:(R一站式读写各种格式文件的包)

最大特点：统一函数 import() / export()，不用记各个包的readxxx/writexxx，自动识别文件后缀。 底层内部调用 readr、data.table、haven、readxl 等，支持csv、xlsx、sav、dta、rds、json、excel等几十种格式。

函数	功能说明	最简示例	
import()	导入数据，自动识别后缀	df <- import("data.xlsx")	
export()	导出保存数据框	export(df, "out.csv")	
convert()	文件格式转换，不用进R环境	convert("input.sav","output.csv")	
import_list()	读取Excel多个sheet，返回列表	lst <- import_list("file.xlsx")	
export_list()	把列表每个元素存为Excel不同sheet	export_list(lst, "multi_sheet.xlsx")

10.R Markdown(报告撰写工具)

把 R代码、文字、公式、图片混写，一键渲染输出 PDF / Word / HTML，科研报告、课程报告、毕业论文、分析笔记主力工具。 文件后缀：.Rmd；三部分：YAML头部、Markdown文本、R代码块。

功能/函数	说明	示例	
YAML头	文档全局配置，放在文件最顶端	--- title:标题 output: html_document ---	
```{r}	R代码块，运行R代码	```{r setup,include=FALSE}	
include=FALSE	运行代码，但不显示代码、不显示输出	```{r setup,include=FALSE}	
echo=FALSE	运行代码，隐藏代码，只展示图/结果	```{r fig.width=6,fig.height=4,echo=FALSE}	
eval=FALSE	只显示代码，不执行代码	```{r eval=FALSE}	
message=FALSE	屏蔽包加载message信息	message=FALSE	
warning=FALSE	屏蔽警告warning	warning=FALSE	
fig.width,fig.height	设置图片宽高英寸	fig.width=7,fig.height=5	
fig.cap="图注"	设置图片图注	fig.cap="iris散点图"	
render("xxx.Rmd")	代码渲染生成文档	render("report.Rmd",output_format="pdf_document")

2.2 Pacman(1个包加载所有的R包)

全名为package manager，即包管理器。

LOAD PACKAGES 加载包

# I recommend "pacman" for managing add-on packages. 
#It will install packages, if needed, and then load the packages.
install.packages("pacman")
# 任选其一 Then load the package by using either of the following:
require(pacman)  # Gives a confirmation message.
library(pacman)  # No message.

#选择要通过pacman加载的R包。
# Or, by using "pacman::p_load" you can use the p_load
# function from pacman without actually loading pacman.
# These are packages I load every time.
pacman::p_load(pacman, dplyr, GGally, ggplot2, ggthemes, 
  ggvis, httr, lubridate, plotly, rio, rmarkdown, shiny, 
  stringr, tidyr)

全部“插件包”加载完毕后加载数据，开展工作

library(datasets)  # Load/unload base packages manually

CLEAN UP 清理包缓存。

# Clear packages
p_unload(dplyr, tidyr, stringr) # Clear specific packages
p_unload(all)  # Easier: clears all add-ons
detach("package:datasets", unload = TRUE)  # For base

# Clear console
cat("\014")  # ctrl+L
